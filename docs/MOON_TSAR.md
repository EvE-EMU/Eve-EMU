# Moon Tsar (disabled)

**Moon Tsar is not installed** in the default slim AA bundle (removed from `INSTALLED_APPS` and the Docker image). Source remains under `deploy/aa_docker/moon_tsar/` if you want to re-enable it later.

For moon rental compliance and scheduling, use **Moon Mining** + **Moon rentals** (`moon_rentals`) and **Mining Taxes** instead — see [ALLIANCE_AUTH.md](./ALLIANCE_AUTH.md).
